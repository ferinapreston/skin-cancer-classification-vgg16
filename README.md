# 🧪 Skin Cancer Classification using VGG16

This project aims to classify skin cancer images using **Transfer Learning** with the **VGG16** model in Keras. The dataset is categorized into benign and malignant skin lesions. The model is trained using thousands of labeled images and evaluated for performance.

## 🛠️ Technologies Used

- Python (Google Colab)
- TensorFlow / Keras
- VGG16 (Transfer Learning)
- Matplotlib, NumPy, Pandas
- scikit-learn

---

## 📈 Model Performance

- **Training Accuracy**: `98.74%`
- **Validation Accuracy**: `96.21%`
- **Final Test Accuracy**: `95.88%`

> *(These results are from the final epoch of the trained model on the full dataset.)*

---

## 🧬 Dataset

The dataset contains thousands of images of benign and malignant skin lesions. It was structured into 3 folders: `train`, `test`, and `val`.
